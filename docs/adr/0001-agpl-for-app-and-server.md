# AGPL-3.0 for the app and the server

Jackdaw exists so a small company can host its own workspace instead of paying a vendor. The app and any sync server are both under AGPL-3.0, with no paid-only features in the core. A copy that is modified and offered as a service has to publish its source. The alternative was a permissive license, or an open client with a commercial server. Both let a host keep improvements private, which is the split this project is refusing.
