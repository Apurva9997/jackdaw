# Jackdaw

An open-source workspace for a small company that would rather host its own pages and databases than pay for a hosted one.

A jackdaw builds its nest from what it picks up. A workspace does the same with notes, documents, and structured work.

Jackdaw is early. The name, the audience, and the license are settled. The product is not built yet.

## What it is for

A small company. Several people edit the same workspace at once, on a server they run themselves. Live updates are part of the product, not a later add-on.
