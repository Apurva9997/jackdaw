# Jackdaw

The workspace a small company hosts itself, so several people can keep pages and databases in one place and see each other's edits as they happen.

## Language

**Workspace**:
The company's Jackdaw, running on a server the company controls. Everyone in it shares one body of pages.
_Avoid_: Notion, vault, account

**Page**:
A named document made of blocks, which can contain other pages.
_Avoid_: Note, doc, file

**Block**:
A single piece of content inside a page.
_Avoid_: Node, element, component

**Database**:
A collection of pages that share a set of properties, shown through one or more views.
_Avoid_: Table, collection, base

**View**:
One way of showing a database. The first views are table, board, and calendar.
_Avoid_: Layout, mode, tab

**Member**:
A person who belongs to the workspace and can edit it with the others.
_Avoid_: User, seat, guest
